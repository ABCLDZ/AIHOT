# 选题雷达

面向公众号创作者的新闻素材工作台，集中收集科技、商业与国际财经报道，帮助整理线索、评估选题和追溯原文。

基于 [AIHOT](https://github.com/KKKKhazix/AIHOT) 改造，保留原项目的 MIT 许可证与作者署名。

## 功能

- **按需更新**：手动采集媒体信源，去重保存，显示各来源的采集状态。
- **信源配置**：提供新华社、人民日报、凤凰、36氪、TechCrunch、金融时报、卫报、彭博、联合早报等媒体配置，可自行增删。
- **材料浏览**：按日期、关键词和主线筛选，保留原标题、摘要、发布时间与原文链接。
- **选题评估**：记录写作切口、读者价值、待补证据和五项人工评分。
- **记录导出**：导出候选 Markdown，支持浏览器人工记录的 JSON 备份与恢复。

默认使用手动采集模式，无需配置模型 API。媒体可用性取决于来源网站及网络环境，采集失败会显示具体状态。新闻报道作为选题线索，写作前仍需核对原文与一手资料。

## 运行

- Node.js 24
- PostgreSQL 17
- npm workspaces

安装、环境配置和数据库初始化见 [部署说明](docs/deploy.md)。使用前复制 `.env.example` 为 `.env`，配置数据库与管理员登录信息。

默认关闭常规自动采集与模型处理，启用手动采集入口。启动 API 和网页后，在 `/admin` 点击“更新选题”获取材料。需要代理时可配置 `EGRESS_PROXY_URL`。

人工标记与笔记保存在当前浏览器；迁移或清理浏览器前请先导出备份。

## 分支

- `wechat-radar`：公众号选题工作台，默认分支。
- `main`：上游版本，供后续对照与更新。
